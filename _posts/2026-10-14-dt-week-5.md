This week, I worked on reimplementing the login system that the project had before refactoring. This meant getting rid of comments that prevented momentarily non-functional code from running and getting rid of cshtml I had built in its place. This process is almost complete. There's currently a bug in the authentication system, as when the app is first accessed, the user is sent to the Projects/Index page despite the fact that there are currently no accounts in the database. This is a problem because only users that have logged in should be directed to the Projects/Index page. All other visitors should be restricted to only viewing the login page, where they are prompted to either log in or create an account. I'm confident that I can have this issue resolved within the next 24 hours, and am optimistic about the week ahead.
